# Contribuer à FEC Audit FR

Merci pour votre intérêt. Contributions publiques et réelles bienvenues : corrections reproductibles, tests, documentation et fonctionnalités utiles.

1. Ouvrir une issue claire (contexte, exemple fictif, résultat attendu).
2. Faire une branche et une modification ciblée ; conserver les contrôles en lecture seule.
3. Ajouter des tests unitaires et exécuter `PYTHONPATH=src python -m unittest discover -s tests -v`.
4. Proposer une pull request avec description et limites.

**Ne jamais soumettre de FEC réels, de données personnelles ou de documents clients.** Les pull requests doivent correspondre à un travail authentique, utile et examiné normalement par les mainteneurs.
